Cluster Builder

Three empty mini PCs, one USB stick, and this page. When it says Done three times, you have a Proxmox cluster with a Home Assistant VM that restarts on another machine if one dies.

1 Tell it about your house

The root password is what you will type once into Cluster Guard later, and into any node's web page (https://<node address>:8006). It is stored here only as a hash.

The three nodes

NameAddressPrivate link address

Give each node a free address on your network, outside the router's DHCP range, and set the second network port of every box on its own little switch for the private link (the link addresses can stay as they are).

The Home Assistant VM

Give that MAC address a DHCP reservation in your router now, so the new Home Assistant keeps the address your old one has. Home Assistant OS will boot on the first node, download its core, and show its Welcome screen, where you restore your backup.

Advanced (leave alone unless you know why)
NodeCluster address (if not the node address)LAN port MACLink port MAC

Normally none of this is needed: the port you cable to your house network becomes the node's address, and the other port becomes the private link.

2 Build the stick image

Downloads the Proxmox installer and the Home Assistant OS image (about 2 GB) and makes one installer image that works for all three machines. Needs internet and free.

    4 Boot each machine from the stick
    
    
    Cable each box to your house network, plug in the stick, power it on. If it does not boot from the stick, press the
      boot-menu key as it starts (F7 on MeLE, F11 or F12 on most others) and pick the stick. The stick erases the
      machine it boots on, so only plug it into the new machines.
    
    
    Each machine installs itself, turns itself off, and waits for you to remove the stick and turn it back on.
      Then it finishes on its own. The first box you boot becomes the first node; do the others whenever you like, together
      or one at a time.
    
    
    
    
    
      
      Forget all machines and progress? The nodes themselves are not touched, only this page's memory of them.
